# ESR-Pack
An all-in-one Windows optimization and gaming readiness pack designed to reduce background overhead, boost FPS, and ensure all essential gaming runtimes are up to date.

## 📦 What's Inside
* **Registry Settings:** Custom `.reg` tweaks to improve system responsiveness, reduce input lag, and prioritize gaming performance.
* **Windows Services:** Configurations to safely disable unnecessary background telemetry and resource-heavy services.
* **DirectX & Visual C++ AIO:** Complete runtime libraries required to prevent DLL errors and crashes in modern and older games.
* **Disk Maintenance:** Quick access to Disk Cleanup and Drive Optimization (Defrag/TRIM) to keep storage fast and clutter-free.

## 🛠️ Recommended Order of Installation
1. **Create a System Restore Point** before making any changes.
2. Install **DirectX** and **Visual C++ Redistributable All In One**, then restart.
3. Apply the **Registry Settings** and **Windows Services** tweaks.
4. Run **Disk Cleanup** and **Defrag & Optimize Disk**, then do a final reboot.
